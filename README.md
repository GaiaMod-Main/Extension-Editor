# GaiaMod Extension Editor!
Built off of AstraBlocktory.

> There is no need to memorize a bunch of obscure Scratch-specific formats to develop extensions; as long as you know JavaScript, you are free to *develop* and *debug* your extensions if you want!

## Development
We use *pnpm* to manage dependencies. You can install the dependencies using the following command:
``` bash
pnpm install
```
Then, start the development server.
``` bash
pnpm start
```
